# Fitness 💪

A modern fitness website built with **HTML5** and **CSS3**, featuring a clean and engaging layout to showcase fitness programs, healthy habits, training exercises, and team members. The design uses Flexbox and CSS Grid to organize content and images across different sections.

## ✨ Features

- **Navigation Bar** — Provides easy navigation across the website.
- **Hero Section** — Introduces the fitness website with an engaging banner.
- **Change Your Habits** — Highlights healthy habits and fitness tips.
- **Training & Exercises** — Showcases training activities and exercise images.
- **Meet Our Team** — Displays team members using an organized layout.
- **Footer** — Contains additional information and closing details.
- **Flexbox & CSS Grid Layouts** — Organizes images and content into structured layouts.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
